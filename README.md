# Tech Academy

Sito statico dedicato alla presentazione di **Tech Academy**,
una scuola di formazione tecnologica.

## Descrizione del progetto

Il sito fornisce informazioni sulla scuola, i corsi disponibili,
i vantaggi dell'iscrizione e i contatti.
È stato realizzato come prova pratica di utilizzo di Git e GitHub.

## Sezioni presenti nel sito

- **Header** — titolo e slogan della scuola
- **Chi siamo** — presentazione della scuola e della sua filosofia
- **I nostri corsi** — elenco dei corsi tecnologici disponibili
- **Perché scegliere Tech Academy** — vantaggi e punti di forza
- **Contatti** — informazioni per contattare la scuola
- **Footer** — copyright

## Comandi Git utilizzati

| Comando | Descrizione |
|---------|-------------|
| `git init` | Inizializza un nuovo repository Git nella cartella corrente |
| `git status` | Mostra lo stato dei file: modificati, in staging o non tracciati |
| `git add .` | Aggiunge tutti i file modificati all'area di staging |
| `git add <file>` | Aggiunge un file specifico all'area di staging |
| `git commit -m "messaggio"` | Salva le modifiche in staging con un messaggio descrittivo |
| `git log --oneline` | Mostra la cronologia dei commit in forma compatta |
| `git branch` | Elenca tutti i branch presenti nel repository |
| `git branch -M main` | Rinomina il branch corrente in `main` |
| `git checkout -b <nome>` | Crea un nuovo branch e si sposta su di esso |
| `git checkout <nome>` | Si sposta su un branch già esistente |
| `git merge <nome>` | Integra le modifiche di un branch nel branch corrente |
| `git remote add origin <url>` | Collega il repository locale a un repository remoto su GitHub |
| `git push -u origin main` | Pubblica il branch `main` su GitHub per la prima volta |
| `git push origin <branch>` | Pubblica un branch su GitHub |
